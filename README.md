# Неоновый Разлом

Браузерная idle RPG с кампанией, 21 героем, коллекцией спутников и автоматическими боями. [Открыть игру](https://lxaraxl.github.io/neon-rift/).

## Запуск и публикация

Проект работает без сборки и сервера приложения. Для локальной проверки запустите `python -m http.server 8000` из корня и откройте `http://localhost:8000/`. Публичная версия публикуется из `main` на GitHub Pages.

- `index.html` содержит игровой экран, боевую механику и состояние игрока.
- `battle-layout.js` задаёт границы платформ и дороги на заставке. `title-chase.js` отвечает за погоню на стартовом экране. `profile-motion.js` рисует портреты с частотой до 60 кадров/с.
- `art/combat/` содержит спрайтовые листы. Для пересборки используйте `python scripts/build-combat-frames.py --jobs 4` с Pillow, NumPy и компилятором C++17. Исходные изображения лежат в `art/miniatures/` и `art/big/`.
- `art/showcase/` содержит 24 кадра для миниатюры каждого героя в коллекции и профиле. Для пересборки используйте `python scripts/build-combat-frames.py --showcase --jobs 4`.
- `art/stride/` содержит ходьбу и бег по 24 кадра на ракурс. Для пересборки используйте `python scripts/build-combat-frames.py --stride --jobs 8`. Для проверки отдельного героя добавьте `--hero silas`.

Команда `node scripts/check-visuals.test.cjs` проверяет звёздные ранги, ракурсы, границы платформ и кадры подмены во время загрузки.

## Что входит в демоверсию

Гостевой прогресс и игровые аккаунты хранятся отдельно в браузере. Игровой аккаунт привязан к устройству, пароль хранится в виде PBKDF2-хеша с индивидуальной солью. Ник выбирается при первом входе. В профиле можно изменить аватар и цвет оформления. Противники арены управляются игрой. Лавка выдаёт тестовые награды.

## Вход через Google и Apple

1. Примените миграцию из `supabase/migrations/` в проекте Supabase. Она ограничивает чтение и запись владельцем и разрешает менять только оформление профиля.
2. Включите Google и Apple в Supabase Auth с данными своих приложений. Укажите URL обратного вызова Supabase в настройках каждого провайдера, а URL игры `https://lxaraxl.github.io/neon-rift/` в разрешённых адресах перенаправления Supabase.
3. Заполните `url` и `publishableKey` в `account-config.js`. Ключи Google, Apple и серверный ключ Supabase хранятся на стороне провайдера.

Без этой конфигурации на GitHub Pages доступны гостевой режим и игровой аккаунт. При включённом облачном входе профиль и прогресс хранятся на сервере.

Для коммерческого выпуска потребуется проверить права на используемые материалы. Реальную оплату, учётные записи и синхронизацию прогресса можно подключить отдельно.
