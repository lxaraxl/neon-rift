# Неоновый Разлом

Браузерная idle RPG с кампанией, 21 героем, коллекцией спутников и автоматическими боями. [Открыть игру](https://lxaraxl.github.io/neon-rift/).

## Запуск и публикация

Проект работает без сборки и сервера приложения. Для локальной проверки запустите `python -m http.server 8000` из корня и откройте `http://localhost:8000/`. Публичная версия публикуется из `main` на GitHub Pages.

- `index.html` содержит игровой экран, боевую механику и состояние игрока.
- `title-chase.js` отвечает за погоню на стартовом экране. `profile-motion.js` рисует портреты с частотой до 60 кадров/с.
- `art/combat/` содержит спрайтовые листы. Для пересборки используйте `python scripts/build-combat-frames.py --jobs 4` с Pillow, NumPy и компилятором C++17. Исходные изображения лежат в `art/miniatures/` и `art/big/`.

## Что входит в демоверсию

Прогресс хранится в браузере. Предыдущая версия сохранения используется как резервная копия. Противники арены управляются игрой. Лавка выдаёт тестовые награды.

Для коммерческого выпуска потребуется проверить права на используемые материалы. Реальную оплату, учётные записи и синхронизацию прогресса можно подключить отдельно.
